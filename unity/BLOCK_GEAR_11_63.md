# BLOCK GEAR 11.63 배치 및 회전 수정

기준 HEAD: `4ad6c04fdbfb344c5cd4d8ade9347afdcf3cf943` (11.62).
작업 전 `git ls-remote`로 unity-prototype HEAD가 같은 값임을 확인했다.

## 변경

- 룰렛 상단을 배경 속 여성들의 손목 부근으로 올렸다. 배경의 30% 높이를
  기준으로 삼고, EnvelopeParent의 세로 잘림도 계산한다. 긴 화면에서는
  원판의 크기를 유지하고, 짧은 화면에서는 아래 정보창 공간을 확보한다.
- 그림으로 만든 외곽 장식은 반지름이 일정하지 않았다. 이 장식과 중심
  보석을 회전 Transform 밖의 고정 프레임으로 옮겼다. 같은 중심·반지름을
  갖는 원형 메시와 11개 숫자만 회전한다. 원판의 좌우 흔들림, 2.5% 크기
  진동, 시작 시 확대 효과를 제거했다. 포인터의 클릭 반응은 유지했다.
- 원형 메시를 둘레 352개 구간으로 세분화했다. 440 논리 단위 반지름에서
  직선 근사 오차는 약 0.018 단위다. 배경이나 장식 이미지의 픽셀은
  변경하지 않았다. 고정된 장식 자체는 여전히 손으로 그린 비대칭 모양이다.
- BLOCK GEAR 제목: 76 → 112. 제목 영역 높이도 108 → 160으로 늘렸다.
- 보상창은 높이 300 고정에서 최소 440으로 바꾸고, 룰렛 아래부터 하단
  안내까지 남은 공간을 채운다. 이름 42 → 60, 능력치 숫자 42 → 66,
  능력치 이름 23 → 32, 수식어 23 → 30, 하단 안내 30 → 38로 확대했다.
  긴 이름·큰 숫자는 각 영역 안에서 크기를 조절한다.
- 사용자 화면에는 공격/방어/체력 이름만 있고 숫자는 보이지 않았다.
  기존 코드는 90 높이 영역에 크기가 다른 두 줄을 넣고 Truncate를
  사용했다. 두 줄 rich text를 없애고 이름과 숫자에 별도 Text/영역을
  배정했다. 최소 카드 높이에서 이름 영역은 63.36, 숫자는 112.64다.
- 블럭 그림의 최대 칸 크기는 54 → 72. 실제 칸 수에 따라 전용 영역에
  맞춰 축소하며 정보 글씨 쪽으로 넘어가지 않는다.
- 버전: `11.63-raised-circular-block-gear-<commit>`, Android versionCode 1163.
