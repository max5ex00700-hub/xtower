# BLOCK GEAR 11.64 손목 높이 기준 보정

기준 HEAD: `44c1afc6f34812f8c165c49c3b873696af55d2f0`.
작업 전 원격 unity-prototype이 같은 HEAD임을 확인했다.

사용자가 새로 지정한 `32312.jpg`를 직접 열어 11.63 미리보기와 비교했다.
기준 사진에서 룰렛 상단 장식 끝은 화면 상단으로부터 약 27% 높이다.
이를 맞추기 위해 배경 기준 WheelStage 시작 위치를 30%에서 26.5%로
올렸다. 장식 PNG 위쪽 투명 여백을 포함하면 보이는 장식 끝이 약 27%에
위치한다. 1536px 높이의 긴 화면에서는 11.63보다 약 54px 올라간다.
16:9 화면에서는 기존처럼 배경의 세로 잘림을 계산한다.

제목, 원형 회전, 확대된 정보창 글씨는 11.63 설정을 유지한다.
룰렛이 올라가며 비는 공간만큼 보상창 높이가 자동으로 늘어난다.

사용자의 공·방·체 표시 질문에 따라 다음 실제 소스를 다시 확인했다.

- ShowOutcome의 블럭 결과 분기는 statRow를 활성화하고, 해당 보상 블럭의
  r.attack / r.defense / r.hp를 각 Text에 넣는다. 일반·전용 블럭 공통이다.
- MakeStatColumn은 공격/방어/체력 이름과 숫자를 별도 영역에 표시한다.
  숫자는 최대 글자 크기 66이며 긴 수치만 영역에 맞춰 줄인다.
- 포획 시도는 블럭 보상이 아니므로 별도 포획 결과 문구를 사용한다.
- 미리보기의 91 / 89 / 134는 디자인 확인용 예시다. 게임 코드는 실제
  보상 블럭 값을 표시하도록 연결되어 있다.

| 화면 높이 (폭 1080) | 룰렛 영역 상단 | 룰렛 영역 지름 | 보상창 높이 |
| --- | --- | --- | --- |
