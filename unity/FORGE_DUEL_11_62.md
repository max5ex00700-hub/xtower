# 대장간 망치 대결 11.62

기준: unity-prototype `76cb70fbbad88033b0f0b5bf234fc4865b859d2d`.
수정 전과 커밋 준비 시 원격 HEAD가 이 값임을 확인했다.

## 원인과 변경

이전 듀얼 배경은 300×533, 천사/악마/모루를 함께 넣은 아틀라스는 400×200이었다.
천사와 악마의 실제 크롭은 각각 117×155, 121×155에 불과했고,
타격은 캐릭터 그림 전체를 회전/이동시키는 방식이었다.

이번에는 듀얼 배경과 캐릭터·모루 그림을 모두 새로 생성했다.
구형 `forge_duel_atlas.bytes` 및 해당 meta를 삭제하고 고정 크롭 코드를 제거했다.
배경에는 캐릭터, 모루, 글자, 결과창이 없다. 실제 UI와 에셋을 별도로 배치한다.

| 에셋 | 실제 PNG 해상도 | 용도 |
| --- | --- | --- |
| forge_duel_background.bytes | 941×1672 RGB | 비율 유지, 화면 전체를 덮는 고딕 대장간 |
| forge_angel_poses.bytes | 2172×724 RGBA | 천사의 준비·들기·내려치기, 각 724×724 |
| forge_demon_poses.bytes | 2172×724 RGBA | 악마의 준비·들기·내려치기, 각 724×724 |
| forge_anvil.bytes | 1536×1024 RGBA | 중앙 모루 및 받침대 |

이미지 생성 도구의 결과 파일을 원래 해상도와 알파 그대로 프로젝트에 복사했다.
확대/색상 축소/알파 재추출 처리를 하지 않았다. 실제 사용한 프롬프트는
`forge-prompts-11.62.json`에 기록했다. 내장 이미지 생성 도구를 사용했다.

## 동작

새 `XTapForgeDuelView`는 화면 연출만 담당한다.

1. `XTapBlacksmith.RunProbabilityMachine`에서 난수를 한 번 뽑아 결과를 결정한다.
2. 천사와 악마가 각각 세 번, 총 여섯 번 번갈아 중앙 모루를 친다.
3. 마지막 타격은 성공이면 천사, 실패이면 악마다.
4. 내려친 자세로 바뀌는 접촉 시점에 결과 문구와 불꽃을 함께 표시한다.
5. 결과를 보여준 뒤 기존 강화/합성/분해 처리 함수에 같은 bool을 전달한다.

캐릭터 이미지를 통째로 돌리지 않는다. 생성한 세 자세를 준비→들기→타격으로
전환하는 키포즈 애니메이션이다. 프레임 보간이나 관절 리깅 애니메이션은 아니다.
타격 순간에는 불꽃, 약한 흔들림과 조명 효과를 더한다.

선택된 실제 블럭 모양을 모루 위에 표시하며 블럭 높이에 맞춰 양쪽 망치 접촉점을
계산한다. 모루가 인물의 발보다 앞에 그려지도록 레이어 순서를 맞췄다.
큰 사각 제물 표시는 없앴고 제물 가치는 상단 설명으로 이동했다.
결과 영역은 220 논리 픽셀로 줄이고 안전 여백과 화면 높이에 맞춰 배치한다.

## 검증

```bash
python3 tools/validate_unity_images.py --build-inputs
python3 tools/preview_forge_duel.py --output unity/forge-review-11.62
git diff --cached --check
```

- 필수 이미지 29개: 청크 길이/CRC/IEND/zlib 및 Pillow verify/load 통과.
- 천사/악마 모두 정확한 3:1 시트, 여섯 프레임 각각의 투명 영역 검사 통과.
- 1080×1920, 1080×2340, 1080×2400, 1080×2520의 정적 배치 검사 통과.
- 제물 가치, 확률 계산, 강화/합성/분해 보상 처리, 재료 소모의 7개 함수가
  기준 커밋과 동일한 것을 소스 비교로 확인했다.
- 확률 처리 함수의 Random.Range 호출은 하나이며, 새 연출 클래스에는
  결과를 다시 결정하는 난수 호출이 없다.
- 빌드 전 PNG CRC와 Unity LoadImage 검사에 더해 해상도, 시트 3:1 비율,
  프레임별 투명 영역 검사를 추가했다.

`forge-review-11.62`의 JPG/MP4는 실제 프로젝트 에셋을 사용한 정적/키포즈
디자인 미리보기다. Unity나 기기에서 촬영한 결과가 아니다. Unity 글꼴,
실제 프레임 타이밍, 렌더링, 터치 복귀는 빌드/실기기에서 확인해야 한다.

버전: `11.62-forge-hammer-duel-<commit>`, Android versionCode: 1162.
