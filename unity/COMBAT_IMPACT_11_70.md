# 전투 연출 전체 연결 11.70

기준 HEAD: `bcf076eddd79b78b941748ee5745f0f37c93df4e` (11.69).
사용자 요청: HIT/실드 현재 대비 가로·세로 2배 + 앞서 미구현으로 보고한 전투 기능 전체 구현.

## 적용 범위

| 항목 | 코드 동작 |
|---|---|
| 표적 크기 | HIT / 추가 HIT / 반격 HIT / 실드의 가로·세로 및 터치 반경을 11.69 대비 2배 |
| 터치 판정 | 표적은 TouchPhase.Began에 즉시 판정. 일반 터치/스와이프는 기존처럼 release 판정 |
| 입력 중복 | 손가락 1개가 제스처 소유. 이미 표적을 처리한 터치의 release, 다른 손가락 release, 취소된 터치는 공격하지 않음 |
| 히트스톱 | 일반 .025초 / HIT·반격 .07초 / 추가 HIT .095초 / 마지막 일격 .10초 |
| 표적 시간 | 전투 전용 시계. 연출 busy/히트스톱/앱 중단/다른 화면에서는 표적 이동과 제한 시간이 함께 정지 |
| 완벽 방어 | 1.05초 실드 중 마지막 .18초. 황금빛과 '지금!' 표시. 성공하면 1.05초 반격 HIT 생성 |
| 반격 | 기본 플레이어 공격 계산 결과에 ×5 적용 후 적 방어력 차감. 반격에서 추가 HIT를 다시 열지는 않음 |
| 콤보 | 성공 공격마다 +1, 3/6/10에서 단계별 문구·파편 수·반동·효과음 피치 강화. 능력치 배수는 추가하지 않음 |
| 콤보 실패 | 허공 터치, 실드 밖 터치, HIT 시간 초과, 실드 시간 초과에 초기화. 랜덤 회피와 자동 일반 반격에는 유지 |
| 타격 | 수정/금속 파편, 교차 섬광, 충격 고리, 실제 피해량 팝업, 짧은 흔들림·확대 |
| 피니시 | 실제 HP가 0일 때 1회 확정, FINISH/화면 띠/대형 파편, 약 .6초 후 다음 층 진행 및 기존 보상 1회 |

기존 일반 공격 ×1 / 스와이프 ×1.6 / HIT ×3.6 / 추가 HIT ×5, 일반 HIT·실드 1.05초,
추가 HIT .70초, 적 회피 20%, 실드 출현 30%, 실드 실패 시 적 공격 ×2는 유지한다.
일반 HIT 성공 시 추가 HIT 한 번이 열리는 기존 연결도 유지한다.

작은 화면에서 커진 표적/타이머가 잘리지 않도록 이동 경계를 반경에 맞게 보정한다.
예: 709px 화면의 표적 사각형 지름 116→232px, 1080px 화면 129.6→259.2px.
표적 중심 기준 원형 판정도 같은 비율로 커진다. 외곽 타이머는 표적의 1.1배이다.

## 구조

- `XTapCombatState.cs`: 표적 종류/전투 시계/완벽 방어/콤보/피니시 1회 확정, 손가락 소유 상태.
- `XTapBattleController.cs`: 실제 입력, 공격·방어·진행·보상, 기존 시스템 연결.
- `XTapCombatEffects.cs`: Image 80개/Text 10개 고정 풀. 매 타격마다 GameObject를 생성·파괴하지 않음.
- 효과 파편은 기존 512px HIT/실드 텍스처를 4×4로 나눈 스프라이트. 캐릭터 원본 이미지는 변경하지 않음.
- 효과용 난수는 별도 System.Random을 사용해 파편 개수가 전투/보상 난수 소비에 영향을 주지 않음.
- 전투 효과음 AudioSource를 음성과 분리. 콤보 효과음 피치가 캐릭터 음성 피치를 바꾸지 않음.
- 방어음은 11.67의 실제 모루 녹음 클립을 재사용. 기존 타격/스윙 5종도 재사용.
- 메인 화면 터치 반응은 기존 TouchPulse를 유지. 전투는 새 병렬 연출을 사용.
- 승리 연출에 포획 전용 `_cap` 이미지를 사용하지 않는다.
- 11.69 감옥 호감도/가방 코드는 변경하지 않는다.

## 실제 검증

```sh
python tools/combat_checks/run.py /path/to/dotnet-sdk-root
```

.NET 8/Roslyn으로 실제 전투 상태 코드 및 컨트롤러에서 추출한 실제 메서드를 컴파일·실행했다.
Unity 객체·코루틴·오디오·게임 외부 의존성은 명시적인 테스트 어댑터이다.

- 전투 규칙 570개 통과: 표적 시간 정지, 완벽 방어 경계, 3/6/10 콤보 단계, 판정 1회, 손가락/취소/연출 중 입력, HP 0 피니시 1회.
- 실제 컨트롤러 메서드 연결 검사 21개 통과: 누르는 순간 피해, release/멀티터치 중복 방지, 추가 HIT 배수·시간, 반격 연결, 일반 방어, 랜덤 회피 콤보 유지, 열린 HIT의 연출 중 시간 보존, 마지막 일격 1회 진행/보상.
- 프로젝트 C# 파일 25개 구문 검사 통과. 전투 컨트롤러 내부 직접 메서드 호출의 누락도 검사했다.
- 타격/스윙 5종과 방어에 재사용하는 WAV의 RIFF 선언 크기 및 PCM 전체 프레임 길이 검사 통과.
- 수정 중 기존 호감도 검사 1,023개와 저장/가방/대사 어댑터 검사 56개도 통과했다.
- Unity Cloud Build 전처리에 같은 전투 순수 규칙 검사를 연결했다. Unity에서는 아직 실행하지 않았다.

**Unity 컴파일·실제 렌더링·실기기 터치·청음·Cloud Build·APK 설치는 미확인. 빌드를 중복 실행하지 않았다.**
