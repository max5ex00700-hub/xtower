# 전용 블럭 장착 칸수 보너스 11.79

## 요청과 적용 규칙

캐릭터 전용 블럭을 장착한 **1칸마다 전체 장착 블럭 능력치 합계에 +1%**를 적용합니다.
유저가 지정한 `(유저 가방 + 캐릭터 가방) +24%`를 기준으로,
기존 블럭 공격·방어·체력을 모두 더한 뒤 칸수 보너스를 한 번 적용합니다.

- 장착한 전용 블럭의 개수가 아니라 `cellCount`를 합산합니다.
- 포획한 캐릭터의 해당 전용 가방에 장착한 블럭만 칸수 보너스를 줍니다.
- 12칸 블럭 2개와 1칸 블럭 24개는 모두 +24%입니다.
- 두 캐릭터 가방의 장착 칸수가 각각 24칸이면 +48%입니다. 캐릭터별 복리로 곱하지 않습니다.
- 호감도로 확장한 칸도 전용 블럭을 장착하면 칸당 +1%입니다. 빈칸은 포함하지 않습니다.
- 소지품·바닥, 미포획 캐릭터, 잘못된 캐릭터 가방 또는 일반 블럭은 보너스 칸수에 포함하지 않습니다.
- 장착 해제·이동·제물 소비 시 현재 장착 상태로 다시 계산합니다.
- 강화·합성·수식어는 칸당 1%를 늘리지 않습니다.

## 계산 순서

공격·방어·체력 각각 다음과 같이 계산합니다.

```text
장착 블럭 합계 = 유저 가방 + 포획한 모든 캐릭터 가방
전용 보너스 배수 = 1 + (장착 전용 블럭 칸수 / 100)
블럭 기여 능력치 = 장착 블럭 합계 × 전용 보너스 배수
전투 능력치 = (플레이어 기본 능력치 + 블럭 기여 능력치) × 기존 전체 수식어 배수
```

블럭의 강화·합성 결과도 장착 블럭 합계에 포함합니다.
이번 칸수 보너스는 블럭 능력치에 적용하며, 플레이어 기본 공격 5·방어 1·체력 100은 포함하지 않습니다.
기존 전체 수식어 배수의 계산 규칙과 적용 범위는 유지합니다.

예: 공격 합계 1,500, 전용 블럭 장착 24칸이면 블럭 공격은 1,860입니다.
수식어가 없으면 전투 공격은 기본 공격 5를 더한 1,865입니다.
전체 수식어 ×2가 있으면 전투 공격은 3,730입니다.

## 코드·화면·저장

- `XTapInventory.ExclusiveEquipmentBonusPercent`에서 현재 장착 상태의 전용 칸수를 합산합니다.
- `EquippedAttack/Defense/Hp`가 전체 블럭 합계에 보너스를 한 번 적용합니다.
- `GetBagDisplayStats`는 각 가방의 기여 능력치에 같은 전용 보너스와 수식어 배수를 적용합니다.
- 메인·가방·감옥에서 전체 블럭 보너스 퍼센트를 표시합니다.
- 머신 전용 블럭 획득 화면과 가방 상세에는 해당 블럭 장착 시 주는 퍼센트를 표시합니다.
- 저장 형식과 개별 블럭 능력치를 덮어쓰지 않습니다. 기존 전용 블럭도 새 계산에 바로 포함됩니다.
- `0` 선택 시 포획/전용 블럭 획득 확률 1%는 별도의 기존 규칙이며 변경하지 않습니다.
