# 6층 캐릭터 혼입 수정 11.78

기준 커밋: `9c2248646c70e0f8435377e96e7a53e15a14c804`, 브랜치 `unity-prototype`.
사용자 제보: 6층 메인에는 6층 캐릭터가 보이지만 전투에서는 5층 캐릭터로 바뀐다.

## 확인한 원인

메인과 전투는 같은 `CurrentVisualFloor()` 계산과 `battleImage`를 사용한다.
문제는 번들 원본 APK의 파일 내용이다. 정상 JPG로 디코딩되더라도 파일명과 캐릭터가 다르다.
전체 캐릭터 이미지 409장을 시각적으로 대조했다. 6층 41장 중 31장에
5층의 보라색 머리 사이보그 캐릭터가 들어 있다. 6층은 갈색 단발 캐릭터다.
1~5층과 7~10층에서는 같은 종류의 캐릭터 혼입을 발견하지 못했다.

| 6층 원본 코드 | 내용 | 처리 |
| --- | --- | --- |
| `p00` | 6층 기본 이미지 | 유지 |
| `p01`~`p09` | 5층 캐릭터 9장 | 제외 |
| `k00`~`k09` | 5층 캐릭터 10장 | 제외 |
| `b00`~`b09` | 5층 캐릭터 10장 | 제외 |
| `d00`~`d01` | 5층 캐릭터 2장 | 제외 |
| `d02`~`d09` | 6층 전투 포즈 8장 | 유지 |
| `cap` | 6층 포획 이미지 | 유지 |

## 수정

- `XTapCharacterArt`에 실제 사용 가능한 이미지 목록을 모았다.
- 6층 및 같은 캐릭터가 반복되는 16층 등의 공격·회피는 확인된 `d02`~`d09`를 사용한다.
  체력 단계 이미지는 `p00`, `d02`, `d04`, `d06`, `d08` 순서다.
  확인된 포즈 8장을 행동별로 재사용하는 수정이며, 빠진 31개의 새 전용 포즈를 제작한 것은 아니다.
- 전투 이미지 선택, 미리 읽기, 도감 목록이 같은 연결 정보를 사용한다.
  도감은 요청한 가상 코드가 아닌 실제 화면에 사용한 이미지 코드를 기록한다.
- 에셋 로더에서도 혼입된 6층 파일을 캐시 조회 전에 차단한다.
- 도감의 6층 수집 대상은 실제 6층 이미지 10장으로 정리했다. 다른 층은 그대로다.
  전체 유효 도감 이미지는 378장이다. 포획 이미지는 전투로 해금하지 않는다.
- 과거 잘못된 이미지 발견 키는 저장소에서 삭제하지 않지만 표시·집계에서 제외한다.
  기존 완료 보상 수령 키를 유지하여 보상을 중복 지급하지 않는다.
  아직 완료하지 않은 사용자는 올바른 10장을 모으면 기존 규칙대로 가방 8칸을 한 번 받는다.
- 원본 APK 두 파트, 포획·1% 확률·호감도·장비·감옥 소스와 저장 키는 그대로다.

## 검증

`tools/character_art_review.json`은 확인한 6층 41장의 SHA-256을 기록한다.
이는 시각 검토한 바이트를 고정하는 자료이며 자동 캐릭터 인식기는 아니다.
`tools/validate_source_apk.py`는 ZIP CRC, 409장 전체 디코딩, 해당 해시를 검사한다.

`python tools/codex_checks/run.py <dotnet-sdk-root>`로 다음을 실행했다.

- 실제 C# 이미지 선택·컨트롤러 메서드 adapter 검사 **25,607개 통과**.
  1~20층의 모든 세부 구간, 체력 단계, 공격/회피 난수 인덱스와 실제 ZIP 경로를 확인했다.
  6층 파일 차단, 확인된 이미지 해시, 미리 읽기, 도감 도달 가능성, 같은 캐릭터 fallback을 확인했다.
- 실제 C# 도감·보상 메서드 adapter 검사 **503개 통과**.
  혼입된 과거 발견값 제외, 포획 이미지 필요 조건, 기존 완료 보상 중복 방지를 포함한다.
- 기존 C# 전투 규칙 **570개**, 컨트롤러 adapter **21개** 통과.
  프로젝트 C# **28개** 문법 파싱 통과.
- ZIP CRC와 **409장 전체 디코딩**, 검토된 6층 **41장 해시** 통과.
- `git diff --check` 통과.

이 검사는 일부 Unity 객체와 난수·렌더링을 adapter로 대체한다.
**실제 Unity 컴파일, Cloud Build, APK 화면·입력 검증은 아직 완료하지 않았다.**
다음 APK에서 5→6→7층, 6층 일반 공격/회피/체력 감소, 도감·포획 이미지를 확인해야 한다.
새 Cloud Build는 시작하지 않았다.
