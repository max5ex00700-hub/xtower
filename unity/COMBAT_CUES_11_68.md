# HIT·실드 디자인 교체 11.68

기준 HEAD: `37ae148bdcdc15491eb22e807b6e981254099fee` (11.67).
시작 시 원격 unity-prototype과 로컬 HEAD 일치 및 깨끗한 작업 트리를 확인했다.

## 디자인

- 일반 HIT: 금속 테두리, 네 방향 첨탑, 금빛 균열 수정, 어두운 중앙 글자판.
- 추가 HIT: 같은 계열의 붉은 금빛 수정과 옆쪽 강조선, `HIT!!` 표시.
- 실드: 금속 테두리, 푸른 유리 수정 면, 밝은 중앙 문양과 뾰족한 방패 실루엣.
- 기존 단색 원/단색 실드 코드에 사용하던 128px 도형 대신 512×512 RGBA PNG 3개를 사용한다.
- 코드로 제작한 원본 벡터 UI다. SVG는 `tools/ui_sources/combat_cues/`에 보관한다.
  캐릭터·배경 작화는 생성하거나 수정하지 않았다.
- 원본은 `tools/build_combat_cues.py`로 다시 생성할 수 있다. 필요한 패키지는
  CairoSVG, Pillow, PyMuPDF다. SVG와 최종 PNG 모두 Git에 저장한다.

## 화면 표시와 연결

`XTapCombatCueSkin`이 세 PNG를 TextAsset에서 읽어 Sprite로 만들고 캐시한다.
일반 HIT와 추가 HIT 시작 시 각각의 스프라이트를 지정한다.
실드와 기존 실드 파편은 새 실드 스프라이트를 사용한다.

기존 활성 표적은 크기가 55%~130%로 변했지만 판정 반경은 고정이었다.
새 표적은 크기를 고정하고 불투명도 0.88~1.0으로 빛이 맥동한다.
표적 사각형의 화면상 너비는 기존 원형 판정의 지름 `2×max(58px, 화면 너비×0.06)`에 맞춘다.
512px 이미지에는 투명 여백과 빛번짐이 있으므로 실제 불투명 실루엣은 그 안에 들어간다.
CanvasScaler의 실제 scaleFactor로 나누어 화면 비율이 달라도 같은 규칙을 적용한다.

HIT 글자는 이미지에 굽지 않고 Unity Text로 표시한다. 표적 크기에 비례해 글자를 정하고
한글 폰트의 큰 행간 때문에 글자가 잘리지 않도록 고정 한 줄의 overflow를 허용한다.
표시 문구는 `HIT` / `HIT!!`다.

이 수정은 표적 디자인·표시 크기·빛 맥동을 적용한다. 기존 움직임/제한 시간/공격 배수/
실드 출현 확률/피격 수치/제스처 판정 시점은 유지한다. 앞서 기획한 완벽 방어·반격·콤보는
별도 기획 상태이며 이 버전에서 새 규칙으로 구현하지 않는다.

## 검증

- 새 PNG 3개: PNG chunk 길이, CRC, zlib 스트림, IEND 및 뒤쪽 데이터, 실제 이미지 디코딩 검사.
- 모두 512×512 RGBA이며 외곽 가장자리 alpha=0. 투명 픽셀 비율 약 39%.
- 빌드 필수 이미지 목록과 Unity BuildConfig의 PNG/실제 LoadImage 검증에 새 3개를 추가.
- 360×800 / 709×1536 / 1080×1920·2340·2400 / 1440×3120에서
  CanvasScaler와 화면 픽셀 지름 변환을 계산해 확인.
- 밝은/어두운 배경에서 116px 축소 디자인을 포함한 비교 보드를 렌더링해 확인.
- `combat-cues-review-11.68/combat-cues-design.jpg`는 **설계 미리보기**이며 Unity 녹화나 스크린샷이 아니다.
- Unity 컴파일, Cloud Build, APK 실기기 화면 검증은 이 환경에서 실행하지 못했다.
