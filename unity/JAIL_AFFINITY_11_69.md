# 감옥 교감 · 호감도 가방 확장 11.69

기준 HEAD: `345892b0c6fa8114980ae4b26139c24b259a7f6e` (11.68)

## 동작

- 포획된 캐릭터마다 독립적으로 저장한다. 기존 가방 소유 규칙과 같이 캐릭터 슬롯 1~10을 사용한다.
- 초상화 터치와 대화 버튼은 같은 보상 경로를 사용한다. 각 캐릭터와 하루 첫 대화에 호감도 +1.
- 한국 시간 00:00에 다음 대화 보상이 열린다. 같은 날 다시 대화하면 말풍선과 터치 반응만 나온다.
- 미접속 날짜 수만큼 호감도를 자동으로 주지 않는다. 실제 대화한 날만 +1.
- 누적 호감도 100마다 해당 캐릭터의 가방 +1칸: 0~99=24칸, 100~199=25칸, 200~299=26칸.
- 이전 논의의 32칸 상한은 확정되지 않았으므로 적용하지 않았다. 900이면 33칸이다.
- 가방 칸 수는 호감도 / 100으로 계산한다. 별도의 중복 수령 가능한 확장 보상을 저장하지 않는다.
- 플레이어 분해/도감 가방 확장, 캐릭터 전용 장비 규칙, 전체 수식어 배수 계산은 유지한다.

## 저장

`xtap_jail_affinity_v1_{characterId}`에 points와 lastTalkDay를 하나의 JSON으로 기록한다.
첫 설치/기존 저장에는 이 키가 없으므로 호감도 0에서 시작한다. 대화 결과를 연출하기 전에 저장한다.

같은 날 연타·감옥 재진입·재접속으로 중복 지급하지 않는다. 저장 실패는 점수와 날짜를 되돌리고 재시도를 허용한다.
손상된 저장은 덮어쓰지 않고 오류를 표시한다. 마지막 보상 날짜보다 시계가 뒤로 가면 날짜 복구 전까지 재지급하지 않는다.
기존 오프라인 앱 구조에 맞춰 기기의 UTC 시계를 사용한다. 서버 시간 검증 기능은 추가하지 않았다.

## 화면

- 좌우로 넘기는 캐릭터 선택 목록: 이름, 호감도, 일일 대화 상태.
- 기존 포획 이미지(cap)를 사용하는 큰 초상화. 없는 경우 같은 캐릭터 p00 이미지로 대체.
- 이미지 비율을 유지해 초상화 영역을 채우고 짧은 화면에서는 아래쪽을 자른다. 이름과 말풍선은 얼굴 영역 밖에 배치한다.
- 캐릭터별 성격을 반영한 대사 3개씩 총 30개, 터치 확대 반응, +1 및 가방 확장 알림.
- 호감도 진행바, 다음 확장까지 남은 점수, 누적 확장 칸, 가방 점유/총 칸 수.
- 해당 가방 공방체 및 전체 수식어 ×배수 적용 표시 유지.
- 캐릭터 1의 X SIGIL BEAT 연결 유지. 다른 캐릭터는 준비 중 표시.
- 안전 영역을 반영하고 매우 짧은 화면에서는 전체 패널 스크롤을 허용한다.
- 감옥이 열려 있을 때 전투/메인 화면 입력 처리로 넘어가지 않는다.
