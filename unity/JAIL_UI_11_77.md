# 감옥 UI 고급화 11.77

기준 HEAD: `abef2edb49512b7c3800f25eb2172fad03f3f21e`, 브랜치 `unity-prototype`.
사용자 요청: 기존 감옥의 품질을 높일 것.

## 화면 변경

- 좁은 초상화 상자를 전체 폭의 캐릭터 배경으로 교체한다. 기존 cap 이미지와 p00 fallback을 사용한다.
  캐릭터 외형/의상/음원/원본 이미지를 새로 만들거나 변경하지 않았다.
- 기존 cap 10장의 얼굴 위치를 비교해 캐릭터별 세로 배치와 목록 썸네일 잘라보기 영역을 조정했다.
  선택 목록과 이름 패널이 얼굴을 가리지 않도록 했다.
- 검푸른 배경, 황동색 모서리 프레임, 버건디색 호감도 패널과 대화 버튼을 구성했다.
  프레임과 감옥/하트/가방/룬/자물쇠 아이콘은 uGUI 벡터로 그린다.
- 문자 목록을 초상화 카드 목록으로 교체한다. 미포획 캐릭터는 자물쇠,
  포획 캐릭터는 이름·오늘 교감 상태, 선택 캐릭터는 금색 테두리를 표시한다.
  선택한 카드가 목록 밖으로 사라지지 않도록 스크롤 위치를 맞춘다.
- 이름/층/일일 상태와 대화 패널을 구분하고, 호감도 수치/다음 100까지 진행률/가방 확장 수를 표시한다.
  장비 공격·방어·체력을 3열로 분리한다.
- 캐릭터 전환 시 0.32초 페이드와 미세한 확대, 호감도 바 보간, 작은 빛 입자 장식을 추가한다.
- 미포획/초상화 누락 안내와 비활성 버튼을 정리한다. 포획 안내는 최신 0 선택 후 1% 규칙을 반영한다.
- 짧은 화면은 세로 스크롤로 하단 버튼에 접근한다. 안전 영역과 긴 화면에 맞춰 재배치한다.
- 초상화 터치 영역을 선택 목록과 이름 패널 사이로 제한해, 제목/상태 영역을 눌러 대화가 실행되지 않게 한다.

## 유지한 동작

- 하루 첫 대화 +1, 한국 시간 00:00 갱신, 호감도 100마다 해당 캐릭터 가방 +1칸.
- 기존 저장 키와 저장 실패/날짜 역행 보호, 포획 여부, 캐릭터별 독립 호감도.
- 전용 가방 연결, 레이나 미니게임 연결, 감옥 위 가방 조작과 메인 입력 차단.
- 11.75 오디오 출력 수정, 11.76 블럭 머신 0 선택 후 포획/전용 블럭 1%.
