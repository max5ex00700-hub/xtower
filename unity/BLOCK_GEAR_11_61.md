# BLOCK GEAR 11.61 화면 재구성

기준 HEAD: `2a51eac227ca53cd8bcebd1c7c06e43c4ba1c408` (11.60).
작업 전 원격 unity-prototype HEAD가 같은 값임을 확인했다.

## 확인한 원인

기존 machine 이미지에는 룰렛, 보상 샘플, 글자까지 그려져 있었다.
실제 회전판과 보상 UI를 얹으면 중복 이미지가 보이는 구조였다.
기존 wheel 이미지의 숫자도 +30이 중복되고 +40이 누락돼 있었다.
배경은 화면에 맞춰 늘어나지만 회전판 크기는 고정돼 있었고, 보상 블럭은
보상창의 자식이 아닌 화면 중심 기준 고정 위치에 있어 화면 비율에 따라
서로 어긋날 수 있었다. 전체 글자 크기에 적용한 3.84배 확대도 제거했다.

## 변경

- 배경을 새 천사/악마 고딕 성당 그림으로 교체했다. UI 글자, 룰렛,
  결과 카드가 없는 배경이며 EnvelopeParent 방식으로 비율을 유지하며
  화면을 채운다. 화면 비율에 따라 가장자리 일부는 잘린다.
- 새 RGBA PNG는 테두리와 중심 보석만 포함한다. 하나의 회전판 위에
  이 투명 장식을 합성하며, 11칸과 숫자는 같은 순서로 한 번만 그린다.
  배경에는 두 번째 원판이 없다. 포인터도 하나만 둔다.
- 시계 방향 순서는 -30, -20, -10, 0, +10, +20, +30, +40, +50, -50, -40.
  i번째 결과에서 원판을 i×360/11도 회전하면 해당 숫자가 12시 방향에 온다.
- 화면 폭을 1080 논리 단위로 맞추고 높이와 Screen.safeArea에 따라
  회전판 크기, 결과 카드, 하단 안내 위치를 함께 계산한다.
- 결과 카드는 블럭 전용 영역과 이름/능력치 영역으로 나눈다. 블럭과
  포획 이미지는 카드 안에 맞춰 표시하고 낙하 애니메이션도 그 영역으로
  제한한다. 긴 이름과 수식어 설명은 영역 내에서 글자 크기를 조정한다.
- 과거 JPEG 내장 복사본과 원형 마스크 가공을 제거했다. Resources의
  새 에셋을 사용하며 투명 PNG의 알파를 보존한다.
- 빌드 전 룰렛 PNG CRC/청크, Unity 디코딩, 투명 영역 비율을 검사한다.
  bundleVersion: `11.61-fullscreen-block-gear-<commit>`, versionCode: 1161.

## 에셋 제작 기록

사용자가 기존 에셋을 폐기하고 다시 제작해도 된다고 허용한 범위 안에서
BLOCK GEAR 배경과 회전판 장식을 이미지 생성 도구로 새로 제작했다.
다음은 제작 요청의 요약이며 원문 프롬프트 사본은 아니다.

배경 요청: 기존 그림의 성인 천사/악마 외형을 참고한 세로 고딕 성당.
왼쪽은 백금색 머리, 흰색·금색 의상과 왕관의 천사, 오른쪽은 검은 머리,
뿔과 검은색·금색 의상의 악마. 깔끔한 2D 애니메이션 인물 윤곽과 큰
머리카락 덩어리, 시네마틱 배경광, 파란빛/불빛 대비. 인물은 상단 양옆,
아래는 비어 있는 바닥. 숫자, 글자, 로고, 룰렛, 결과 창은 넣지 않는다.

장식 요청: 정면 원형 룰렛용 고딕 금속 테두리와 중앙 파란 보석.
검게 산화된 금속, 오래된 금색 장식, 사파이어/호박색 작은 보석.
중심과 테두리 사이 및 원 바깥은 투명하게 유지한다. 숫자, 칸 구분선,
포인터, 배경, 글자를 넣지 않는다. 정확한 수치는 런타임에서 표시한다.

| 프로젝트 파일 | 실제 저장 형식 | 해상도 | 파일 크기 |
| --- | --- | --- | --- |
| block_gear_machine.bytes | RGB JPEG | 2048×4068 | 1,796,652 bytes |
| block_gear_wheel.bytes | RGBA PNG | 1254×1254 | 1,151,236 bytes |

배경 생성 결과는 890×1768이었다. 이를 Lanczos로 2048×4068에 리샘플링해
JPEG 품질 92로 저장했다. 네이티브 2048×4068 생성 결과는 아니다.
장식은 생성된 1254×1254 해상도와 투명도를 그대로 유지해 저장했다.

## 검증 범위

```bash
python3 tools/validate_unity_images.py --build-inputs
python3 tools/preview_block_gear.py --output unity/ui-review-11.61
git diff --check
```

- 필수 이미지 27개: PNG 청크/CRC/zlib 및 Pillow verify/load 검사 통과.
- 정적 배치: 1080×1920, 1080×2340, 1080×2400, 1080×2520 확인.
  긴 화면에는 상단 90~110px, 하단 60~80px 안전 여백을 가정했다.
  원판/결과 창/안내 영역 분리와 긴 블럭의 영역 내 배치를 검사했다.
- `ui-review-11.61` 그림은 새 에셋과 같은 배치 계산으로 만든 **정적 디자인
  미리보기**다. Unity 스크린샷이 아니다. 글꼴, 실제 Text 줄바꿈,
  캔버스/마스크 동작과 애니메이션은 Unity에서 별도 확인이 필요하다.
- 이 환경에는 Unity가 없다. C# Unity 컴파일, Unity LoadImage 실행,
  Cloud Build, APK 설치/실기기 검증은 수행하지 않았다.
- 11.60에서 기록한 구형 아틀라스 3개 손상은 이번 BLOCK GEAR 수정 범위
  밖에 남아 있다. 전체 게임의 모든 에셋이 정상이라는 의미가 아니다.
