사용 안내

1 · 이미지 고르기

  1. 사진을 끌어다 놓거나, 카메라·갤러리 버튼으로 올립니다.
  2. 배경이 단순하고 물체가 한가운데 또렷한 사진일수록 결과가 좋습니다.
  3. 배경이 투명한 PNG는 그대로, 일반 사진은 자동 누끼(배경 제거) 후 전송합니다.

2 · 엔진 선택

TRELLIS.2
마이크로소프트 오픈소스 모델을 Hugging Face Space로 무료 사용. HF 토큰이 있어야 GPU 사용량이 잡혀 안정적입니다.
Tripo3D
유료 API. 본인 키를 넣으면 고품질 PBR 모델 생성 (가입 무료 크레딧).
Meshy
유료 API. 본인 키를 넣으면 고품질 PBR 모델 생성 (무료 플랜 크레딧).

3 · 뷰어 조작

  • 드래그·핀치로 360° 회전/확대, 자동회전·와이어프레임·배경 전환 제공.
  • GLB 버튼으로 모델 파일을 내려받아 다른 3D 프로그램에서 열 수 있습니다.

키 발급

  • Hugging Face 토큰 — huggingface.co/settings/tokens (Read 권한이면 충분)
  • Tripo3D 키 — platform.tripo3d.ai/api-keys
  • Meshy 키 — meshy.ai/settings/api

안내

  • 업로드한 이미지와 생성 요청은 선택한 엔진(Hugging Face / Tripo / Meshy)으로 전송됩니다.
  • TRELLIS.2 무료 GPU는 혼잡하면 대기·실패할 수 있습니다. 잠시 뒤 다시 시도하세요.
  • API 키는 이 브라우저에만 저장되며 제작자 서버로 보내지 않습니다. (Tripo·Meshy는 CORS 중계 프록시만 경유)
